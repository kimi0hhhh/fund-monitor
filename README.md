## 2. 安装与启动

### 2.1 首次安装（下载 exe，无需解压）

1. 到 **Releases** 页面下载最新版 exe（如 `FundMonitor-v2.0.13.exe`），可自行改名为 `基金监控.exe`
2. 把 exe 放到任意目录（路径建议纯英文，如 `D:\FundMonitor`），双击即可运行，**无需安装、无需 Python**
3. 首次运行会在 exe 同目录自动生成持仓等数据文件
4. 依赖 **WebView2 运行时**（Windows 11 和绝大多数 Win10 已自带；缺失时到微软官网搜索 "WebView2 Runtime" 下载安装）

### 2.2 从源码构建（开发 / 改代码后重新打包）

1. 克隆仓库：`git clone https://github.com/kimi0hhhh/fund-monitor.git`
2. 确保已安装 **Python 3.10+**（安装时勾选 "Add to PATH"）
3. 在项目根目录打开命令行，执行一键构建（自动创建虚拟环境 → 安装依赖 → 打包）：

   ```
   python build.py
   ```

4. 产物在 `dist\基金监控.exe`；加 `--copy-to` 可自动复制到指定目录：

   ```
   python build.py --copy-to D:\桌面
   ```

- 更多参数见 `python build.py --help`（如 `--venv` 复用已有环境、`--skip-install` 只打包）
- 已打包好的成品可直接在 Releases 页下载，无需构建

> 换电脑迁移：把旧电脑 exe 同目录下的所有 `.json` 文件一起拷到新电脑 exe 同目录即可。

## 3. 持仓监控（免费，无需 AI）

> 持仓功能完全免费、不依赖 LLM，断网也能看历史数据。

### 3.1 录入持仓

1. 点「**＋ 录入持仓**」
2. 输入 **6 位基金代码**（如 `110022`），系统自动识别名称
3. 输入持有金额（元）
4. 选择确认规则（T+0 / T+1 / T+2）
5. 确认后按当前净值自动折算成份额

### 3.2 买入（加仓）

1. 在表格中选中该基金（或先输入代码）
2. 点「**买入**」，输入金额（元）
3. 按该基金的 T+N 规则自动确认净值日（见 3.6）

### 3.3 卖出（减仓）

1. 选中该基金后点「**卖出**」
2. 输入金额（元），或输入「全部」清仓
3. 按 T+N 规则结算，T+N 天后到账生效

### 3.4 改规则

- 选中一行点「**改规则**」，设置该基金确认天数（0 / 1 / 2）
- 不同基金规则不同：货币基金可 T+0，普通股票/混合/债券默认 T+1，QDII 跨境基金 T+2

### 3.5 编辑 / 删除

| 操作 | 说明 |
|---|---|
| **✎ 编辑** | 修改持仓金额 + 累计收益（用于修正历史误差） |
| **删除** | 移出列表，**有二次确认弹窗**，删除前请三思 |

### 3.6 基金交易规则（T+N）详解

- **买入**：交易日 **15:00 前**提交 → 按**当天**净值折算份额，**T+N** 天后确认到账；
  **15:00 后**或周末提交 → 顺延到**下一个交易日**的净值
- **卖出**：同样的 15:00 截止规则，按确认净值日结算金额，T+N 天后到账生效
- 待确认的交易显示在底部「**待确认交易**」列表（含净值日和到账日），确认后自动消失
- 点「**撤单**」可取消尚未确认的交易
- 说明：交易日历只区分工作日/周末，法定节假日不单独判断（会随净值日期自然顺延）

### 3.7 表格与刷新

- **排序**：点击表头任意列可多级排序（名称/涨幅/金额/收益/份额/净值等）
- **占比列**：持仓市值占比，超过 30% 显示橙色「集中」警示
- **涨幅来源标注**：涨跌幅旁标注数据来源——盘中估算显示「**预估**」；官方数据且日期=今天显示「**收盘**」；昨日数据（今天未开盘）显示「**昨日收盘**」
- **收盘后用官方数据**：交易时段（9:30-15:00）用盘中估值兜底；**收盘后/周末直接用基金官方净值与涨跌**，不再被估算覆盖（保证显示准确）
- **自动刷新**：每 30 秒自动更新行情；点「立即刷新」手动刷新

## 7. AI 投研分析

> 需要 DeepSeek API key（见第 11 节配置）。

### 7.1 单只基金分析

1. 顶部点「**分析**」→「今日分析」tab
2. 选择基金 → 点「**🤖 开始分析**」
3. 后台流水线执行（约 30-60 秒）：
   ```
   拉取90天历史净值 → 计算MA/RSI/回撤/波动率
   → 九角色AI（技术/基本面/新闻/情绪 → 多空辩论 → 主管 → 交易员 → 风控 → 风险主管）
   → 输出结构化报告
   ```
4. 报告包含：
   - **核心结论**：一段话总结
   - **今日分析**：趋势 / 关键价位 / 动量 / 风险
   - **明日预测**：方向（UP/DOWN/FLAT）/ 幅度 / 信心值
   - **加减仓建议**：操作（买入/加仓/持有/减仓/卖出）/ 仓位 / 入场区间 / 目标价 / 止损位
   - **中期策略**：未来数周的判断
   - **关键风险与催化**：利空/利好因素
   - **技术指标摘要**：MA 多空排列、RSI、回撤、波动率
   - **持仓穿透**：该基金前十大持仓及行业分布（自动拉取）
   - **信号**：AI 判断是否生成可追踪信号

### 7.2 全部持仓组合分析

- 点「分析」tab 后，选择「**全部持仓**」或类似入口（若存在）
- 执行顺序：**逐只分析 → 组合级分析**，组合报告包含：
  - 整体预测（组合明日方向）
  - 板块/行业调整建议
  - 闲钱配置建议（结合单基金建议）
  - 新方向推荐
  - **量化配置**：风险平价算法给出的各基金建议仓位
- 逐只分析结果**按四档排序**：
  1. 明确操作建议（买入/加仓/卖出/减仓）
  2. HOLD 但带附加说明
  3. 纯 HOLD
  4. 分析失败
  - 档内按信心值降序 → 持仓金额降序
- **复盘联动（结论依据来源）**：分析报告顶部展示「🧭 复盘联动」块——本次分析参考的**加减仓复盘经验**（盈利占比/偏差类型/经验教训）和**预测复盘修正**（方向正确率/偏差率修正值/基准对照/信心校准）原文，让你清楚结论是怎么得出来的；「📡 信号联动」块展示参考的历史信号与胜率

### 7.3 风险指标（逐只分析附带）

- **Sharpe** 夏普比率
- **VaR95** 95% 在险价值（单日最大可能亏损）
- **下行风险**
- **最大连跌**（最大回撤）

## 8. 预测复盘

1. 「分析」→「**复盘**」tab
2. **选择预测目标日**（下拉显示「对 08-18 日」）→ 点「**📋 复盘对所选日的全部预测**」
   - 复盘锚定**目标日**：预测记录自动带 `forecast_date`（交易日 15:00 前分析 → 对当日；15:00 后及周末 → 对下一交易日）
   - **跨分析日聚合**：「对某日」的预测可能分散在多个分析日（如 17 号晚和 18 号盘中都预测 18 号），自动合并成一次复盘
3. 自动对比该目标日预测 vs 实际（**官方收盘涨跌**），输出：
   - 方向是否正确（UP/DOWN/FLAT 对比）
   - 幅度偏差
   - 综合准确率（**0-100 分**：方向对得 50 分；幅度误差 <0.3% 再得 50 分，<0.6% 得 30 分）
   - 组合实际涨跌（持仓市值加权）
   - **AI 偏差原因分析**：每只有偏差（方向错或幅度偏 ≥0.3%）的基金逐只解释原因
4. 复盘结果顶部四块统计：
   - **方向正确率 / 平均准确率 / 幅度偏差率**（只算方向判对的样本，实际−预测均值；为正=系统性低估）
   - **📊 基准对照**：AI 方向正确率 vs 动量跟涨 / 均值回归 / 历史频率 / 随机 4 个基线（只用分析日当天及以前数据，防数据泄漏）+ 超额正确率
   - **📊 信心校准**：AI 自评高/中/低信心档位的实际正确率（验证信心是否可信）
5. **复盘闭环（自动喂回下次分析）**：复盘完成后提炼经验，下次任何分析自动带上：
   - 方向正确率 + 幅度偏差率修正值（如 +3.09% → 指示 AI 预期涨幅相应上调）
   - **滚动修正**（近 5 次复盘 × 样本量 × 时间衰减加权，避免单次极端行情带偏）
   - 基准对照 + 信心校准 + 经验教训
6. 「**历史预测**」tab：按目标日查看「对 X 日的预测」详情（跨分析日聚合）

## 9. 信号追踪

- 「分析」→「**信号**」tab
- AI 在分析时会生成可追踪信号（如"突破关键位看多"），自动入库（去重：同一基金+方向+目标只留一条）
- **状态徽章**：进行中 / 强化 / 弱化 / 兑现 / 证伪
- **AI 自动审核**：打开信号页自动审核进行中的信号（**5 小时内不重复自动审**，重启后仍生效；手动点「AI 审核信号」按钮不受限），判定：
  - 兑现（判断正确）/ 证伪（判断错误）/ 强化 / 弱化 / 维持原判 / 信息不足
- **胜率统计**：4 宫格（总信号 / 进行中 / 已了结 / 命中率）
- 支持**删除单个信号**、**一键清空**

### 9.1 信号审核会影响分析吗？（逻辑说明）

**审核本身不干扰分析执行，但审核结论是下次分析的参考输入**：

- **独立流程**：信号审核只在打开「信号」页面时自动执行，只更新信号的状态与结果，**不修改分析逻辑、不阻塞分析**。无论是否审核，你随时可以正常点「开始分析」。
- **闭环引用**：每次分析（单只/组合）时，程序会把该基金的历史信号列表拼进给 AI 的提示词中，并要求 AI「参考修正本次判断，并在信心值中如实反映影响」。例如：
  - 某信号此前被审核为 **证伪**（如"看多但实际下跌"）→ 下次分析时 AI 会看到这条失败记录，**下调信心值**、避免重复同一方向错误
  - 某信号被审核为 **兑现** → AI 会知道该判断已应验，作为确认依据
- **信号 ≠ 加减仓建议**：信号是方向性判断记录（供 AI 自我修正），加减仓建议是具体的操作指令（走加减仓复盘闭环），两套机制独立但共同作用于下次分析的提示词。

## 10. 加减仓复盘（闭环机制）

> 这是本工具最有特色的功能：**AI 的加减仓建议 → 自动验证 → 提炼经验 → 喂回下次分析**，形成持续改进闭环。

### 10.1 建议如何产生

- 每次「今日分析」或「组合分析」后，若 AI 给出**非持有**操作（买入/加仓/卖出/减仓），该建议自动存入「加减仓复盘」库（同一基金**同一目标日**只留最新一条）
- 建议同样带**目标日锚点**（forecast_date，与预测一致）：15:00 前分析 → 对当日；15:00 后及周末 → 对下一交易日。页面卡片显示「生成日 · 对 08-18 日」

### 10.2 何时自动复盘

复盘**只按开市日**进行，且**等基金当日净值更新完**：

| 条件 | 说明 |
|---|---|
| 今天是开市日 | 用沪深300指数行情判断，**周末和法定节假日都不算** |
| 时间 ≥ 23:00 | 基金净值通常晚上才更新完，等 23:00 后数据才可靠 |
| 建议目标日 ≤ 今天 | **只复盘「对今天及以前」的建议**——"昨天给的对今天的建议"当晚复盘；「对明天」的建议等目标日收盘后 |
| 净值新鲜度 | 复盘前校验当前行情净值日期 ≥ 目标日：**QDII 等 T+N 基金净值滞后 1-2 天时跳过**，标记「净值未更新…待更新后自动复盘」，等净值更新后补复盘，避免用旧净值算出错误盈亏 |

**触发方式**：
- 程序开着：启动时自动设好 23:00 定时器，到点自动复盘一次
- 23:00 后打开程序：启动 3 秒后自动补一次
- 打开「加减仓复盘」页面：自动检查并触发（60 秒防抖）

**举例**：
- 周六分析的建议（对周一）→ 下周一 23:00 后自动复盘 ✅
- 周五盘中分析的建议（对周五）→ 周五 23:00 复盘 ✅
- 周五 23:00 没开电脑 → 下周一 23:00 补（建议不会丢，只会顺延）✅
- 周一晚给的对周二建议 → 周二 23:00 复盘；其中 QDII 净值滞后 → 自动等净值更新后再补 ✅

### 10.3 复盘内容

每条建议复盘后给出：
- **结果**：盈利 / 亏损 / 持平（按建议方向估算——买/加仓看净值涨跌为正，卖/减仓反过来）
- **收益率**：如果听了这条建议，到现在赚/亏百分之几
- **偏差类型**：方向误判 / 时机过早或过晚 / 追涨杀跌情绪化 / 幅度误判 / 信息不足 / 其他
- **原因**：AI 的盈亏原因与偏差分析（60 字内）

### 10.4 闭环：经验教训喂回下次分析

复盘完成后自动执行：
1. 把最近 12 条复盘记录（含偏差类型/原因/盈亏）交给 AI 提炼 **3-6 条经验教训**
2. 缓存到 `trade_lessons.json`
3. **下次任何分析**（单只/组合）都会自动带上这段上下文：
   - 盈利占比 + 平均收益
   - 偏差类型分布
   - 复盘经验教训
   - 最近 3 条亏损案例（含偏差类型）
4. AI 在生成新建议时会参考这些历史教训 → 闭环

### 10.5 页面功能

- **日期筛选**：顶部下拉框按**目标日**筛选复盘记录（全部 + 各目标日倒序，卡片显示「生成日 · 对 X 日」）
- **状态提示**：显示「今天休市 / 今日净值未更新完」等实时状态
- **经验教训区块**：页面顶部展示当前缓存的经验教训（注明生成日期）

## 13. 常见问题 FAQ

**Q1：窗口打不开 / 白屏？**
缺少 WebView2 运行时。到微软官网下载 "WebView2 Runtime" 安装后重开。

**Q2：添加后显示"未找到"？**
请确认是 6 位基金代码（如 110022），本工具只支持基金，不支持股票代码。

**Q3：估值不更新？**
非交易时间（交易日 9:30-15:00 之外）没有盘中估值，显示的是最新官方净值涨跌。

**Q4：杀毒软件报毒？**
PyInstaller 打包的单文件 exe 偶尔被误报，添加信任即可。

**Q5：买入后长时间没确认？**
确认在 15:00 前买入且当天是交易日；若跨法定节假日，确认会顺延到节后首个交易日。

**Q6：分析报"请配置 API key"？**
「分析」tab → 右上角「⚙ 设置」→ 填入 DeepSeek key → 保存。

**Q7：分析调用失败？**
检查 key 是否正确、余额是否充足、网络能否访问 api.deepseek.com。

**Q8：加减仓复盘一直显示"待复盘"？**
看顶部状态提示：休市日或 23:00 前不会复盘，属正常等待；下个开市日 23:00 后自动补。

**Q9：换电脑怎么迁移？**
拷贝 exe + 同目录所有 `.json` 到新电脑同一目录（或用「便携版」压缩包）。

**Q10：盘中估值和实际结算不一样？**
估值是估算值，仅供参考，实际以基金公司结算为准。
